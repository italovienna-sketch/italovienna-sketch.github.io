Nota de Transparência & Escopo do Projeto

Prova de conceito independente desenvolvida para estudo técnico de visão computacional aplicada a desafios de segurança industrial. Não possui vínculo oficial com nenhuma empresa, não utiliza imagens corporativas, não é um sistema certificado e não substitui a supervisão humana de segurança do trabalho.

01 // Visão Geral

Contexto do Projeto

O VisionSafe AI investiga como modelos leves de visão computacional (YOLO11n rodando via ONNX Runtime Web em Web Worker) podem auxiliar na conferência visual de Equipamentos de Proteção Individual (óculos de segurança, protetor auricular e touca) usando apenas a câmera do celular, sem enviar ou gravar nenhuma imagem em servidores externos.

02 // Problema Identificado

O Desafio Real

Sistemas tradicionais de visão computacional para segurança industrial costumam exigir servidores dedicados com GPU, câmeras fixas de alto custo e transmissão contínua de vídeo pela rede — gerando barreiras de privacidade, latência e infraestrutura. Além disso, detectores ingênuos tratam qualquer falha de câmera ou oclusão como 'infração', gerando falsos alarmes.

03 // Conceito

Abordagem Arquitetural

Processar 100% da inferência no próprio aparelho (offline-first após o primeiro carregamento) e substituir decisões binárias precipitadas por uma máquina de estados honesta sobre a incerteza óptica: Detectado, Não confirmado e Não avaliável.

04 // Solução Proposta

Como o Sistema Funciona

Uma PWA em React + TypeScript que executa inferência com ONNX Runtime Web em Web Worker isolado. O sistema acompanha cada pessoa separadamente ao longo de uma janela temporal configurável (5s) e informa três estados claros por EPI: 'Detectado', 'Não confirmado' (quando o item não foi visto na janela, cabendo sempre ao técnico conferir) e 'Não avaliável' (quando a imagem está distante, borrada, escura ou com baixa confiança — nunca acusando falsamente). Inclui ainda uma bancada de testes com gabarito (precisão, revocação, latência) e exportação CSV.

05 // Processo de Desenvolvimento

Engenharia & Execução Passo a Passo

  • Construção da interface mobile-first com controle explícito da câmera (indicador permanente de câmera ativa e liberação imediata de hardware ao parar).
  • Integração do ONNX Runtime Web em Web Worker para manter a interface fluida enquanto modelos YOLO11n processam os quadros localmente.
  • Modelagem da máquina de estados por pessoa com janela temporal de 5 segundos e diagnóstico de qualidade óptica (distância, nitidez, iluminação).
  • Criação de 114 testes automatizados (unitários com Vitest + E2E com Playwright) validando privacidade de rede (zero requisições externas de imagem), modo offline e operação contínua.
06 // Minha Contribuição

Idealização da prova de conceito inspirada em desafios reais de segurança industrial, definição das regras de estados de incerteza ('Não avaliável' vs. 'Não confirmado'), treinamento/exportação experimental de modelos em Python e desenvolvimento assistido por IA da PWA e suíte de testes.

07 // Status Atual & Stack

Protótipo experimental independente publicado para demonstração técnica (interface e pipeline validados; modelos de produção restritos por licença de dataset).
